# 우리 아기 육아일기 (Baby Diary PWA)

엄마·아빠가 같은 날 각자 기록을 남기는 **우리 아기 육아일기**입니다. 설치 없이 브라우저로 열고, 홈 화면에 추가하면 앱처럼 쓸 수 있어요. 모든 기록은 **그 기기의 브라우저 저장소(localStorage)** 에만 남고 서버로 보내지 않습니다.

## 페이지

| 페이지 | 내용 |
| --- | --- |
| 1p 가족 소개 | 엄마·아빠·아기 이름, 아기 생일(양력/음력·윤달), **출산 예정일**(임신 중), 엄마·아빠 생일, 백업(텍스트 복사·붙여넣기 / .txt 파일 저장·공유·불러오기) |
| 2p 첫 만남 | 엄마·아빠의 첫 만남 / 아기와의 첫 만남 (사진·이야기·날짜) |
| 3p 탄생 기록 | 태어난 곳·시간·몸무게(kg/g)·키·출생 메모·사진 |
| 4p 오늘의 일기 | 날짜 이동, 생후 일수(태어나기 전에는 만남까지 D-N·임신 주수), 엄마/아빠 작성자 선택, 여러 건 기록, 기분·수유·수면·태그, 사진, 수정/삭제, **이 날 일기 공유 링크**, **카드 PNG 저장** |
| 5p 아기 정보 | 양력↔음력, 띠(입춘 안내), 별자리, 탄생석, 탄생화·꽃말, 100일·첫돌·다가오는 생일 D-Day, 엄마·아빠 생일 — **출산 예정일만 있으면 예정일 기준 미리보기**(만남까지·임신 주수 280일 역산) |
| 6p 병원·약국 | 카카오 지도에서 주변 **소아과·약국·야간·응급·어린이집** 찾기, 필터 칩·동네/병원명 검색·📍 내 위치, 거리·도로명 주소, 📞 전화하기(`tel:`)·🗺️ 카카오맵 길찾기 |
| 7p 동화책 | 한·영 동화 4편(각 5장), **한영 함께·한국어만·영어만** 전환, 🔊 영어/한글 듣기·🐢 천천히(0.65배)·⏹ 멈춤, 영어 단어 터치 → 뜻·발음 카드, ⭐ **내 단어장**(localStorage)과 간단 퀴즈 |

공유 링크(`#share=...`)로 들어가면 **그날의 일기만** 편지지 카드로 보이고, 하단의 작은 "내 육아일기장 열기" 버튼으로 앱에 들어옵니다.

## 실행

`file://` 로 열면 서비스워커(오프라인 캐시)가 동작하지 않습니다. 로컬에서는 아래처럼 간단한 서버로 확인하세요.

```bash
cd baby-diary
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## GitHub Pages 배포

1. GitHub에서 **Public 빈 저장소**를 하나 만듭니다(예: `baby-diary`).
2. 이 폴더의 파일을 그대로 올립니다.

```bash
git init
git add .
git commit -m "우리 아기 육아일기 PWA"
git branch -M main
git remote add origin https://github.com/<계정>/baby-diary.git
git push -u origin main
git push origin main:gh-pages
```

3. 저장소 **Settings → Pages** 에서 Source가 `gh-pages` 브랜치 루트로 잡혀 있으면 `https://<계정>.github.io/baby-diary/` 로 열립니다.
4. 이후 수정할 때는 **`main` 과 `gh-pages` 두 브랜치를 모두** 갱신해야 라이브에 반영됩니다.

> 아이폰: Safari에서 주소를 연 뒤 **공유 → 홈 화면에 추가** 하면 standalone 앱처럼 실행됩니다.
> 새 버전을 올렸는데 화면이 그대로면, 앱을 완전히 닫았다가 다시 열면 서비스워커가 갱신됩니다.
> `sw.js` 의 `CACHE` 이름(`baby-diary-toss-v5`)을 올리면 강제로 새 캐시를 씁니다.

## 동화책 (7p)

- 동화 4편은 `js/story.js` 안에 글·그림(이모지)·단어 사전이 함께 들어 있어 **인터넷이 없어도** 읽고 뜻을 볼 수 있습니다.
- 읽어주기는 브라우저 **Web Speech API**(`ko-KR`·`en-US`)를 씁니다. 지원하지 않는 브라우저에서는 한국어 안내 문구가 뜨고 글은 그대로 볼 수 있습니다.
- 영어 단어를 누르면 **내장 뜻**이 먼저 보이고, 인터넷이 되면 `api.dictionaryapi.dev` 에서 **발음 기호와 원어민 음성**을 더해 줍니다. 못 불러오면 기기 음성으로 발음합니다.
- 담은 단어는 `localStorage` 의 `babyDiary.vocab.v1` 에만 저장되며(서버 전송 없음), 2개 이상이면 단어장 안에서 퀴즈가 나옵니다.

## 병원·약국 지도 (6p)

- 카카오 지도 JS SDK(`libraries=services`)로 주변 장소를 찾습니다. 앱 키는 `js/map.js` 상단 `APP_KEY` 하나만 바꾸면 됩니다.
- Kakao Developers → 내 애플리케이션 → **플랫폼 > Web** 에 `https://kimgeunho4302-cmd.github.io` 가 등록되어 있어야 하고, **카카오맵 사용 설정**이 켜져 있어야 지도·장소 검색이 동작합니다.
- 위치 권한을 허용하지 않으면 **서울시청**을 기준으로 보여 주고, 지도 SDK가 로드되지 않으면 목록 자리에 안내와 함께 `카카오맵에서 보기` 링크를 보여 줍니다(오프라인·도메인/사용 설정 문제).
- 서비스워커는 같은 출처 요청만 다루므로 `dapi.kakao.com`·`daumcdn.net` 타일 요청은 캐시하지 않습니다.

## 데이터·백업

- 기록은 브라우저 저장소에만 있습니다. **브라우저 데이터 삭제 / 시크릿 모드 / 기기 변경** 시 사라지므로 1p에서 가끔 백업하세요.
- 백업은 세 가지 길이 있습니다. ① **백업 텍스트 복사 → 붙여넣기로 합치기**(안드로이드·아이폰 모두 확실), ② **파일로 저장·공유**(`navigator.share` 파일 공유, 안 되면 `baby-diary-backup-YYYY-MM-DD.txt` 다운로드), ③ **파일 불러오기**(`.json`·`.txt` 모두 가능).
- 엄마 폰·아빠 폰에서 따로 쓰다가 한쪽에서 백업을 합치면 같은 날 일기는 id 기준으로 중복 없이 합쳐집니다.
- 사진은 올릴 때 **긴 변 900px, JPEG 0.75** 로 자동 축소해 저장합니다.

## 데이터 출처

- **음력**: 한국천문연구원(KARI) 음양력 자료 기반 1900~2050년 월 데이터를 내장했습니다(`js/lunar.js`). 1900-01-31 ~ 2050-12-31 **모든 날짜(55,122일)** 를 KARI 변환 결과와 대조해 검증했고, 윤달도 전 구간 확인했습니다. 2027년 설날(2/7)처럼 중국 음력과 하루 다른 해도 한국 기준으로 계산됩니다.
- **탄생화·꽃말**: 국내 화훼 자료의 366일 목록(2/29 포함)을 내장했습니다. 자료마다 조금씩 다를 수 있어 날짜별 꽃과 함께 그 달의 대표 탄생화도 같이 보여 줍니다.
- **띠**: 음력 설날 기준. 사주(명리)의 입춘 기준은 안내 문구로 덧붙였습니다.
- **별자리**: 양력 날짜의 12궁 구간. **탄생석**: 1~12월 현대 표준 목록.

## 음악

외부 오디오 파일 없이 **Web Audio API로 직접 연주**하는 오르골 자장가 3곡입니다(반짝반짝 작은별 · 오르골 자장가 · 포근한 달빛 아르페지오). 오른쪽 아래 미니 플레이어에서 재생/일시정지·곡 전환·볼륨을 조절합니다. 모바일에서는 멈춰 있을 때 동그란 버튼 하나로 접혀 있습니다.
